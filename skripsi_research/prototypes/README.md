# 🎨 Direktori Prototipe Desain Antarmuka (UI/UX)

Direktori ini memuat prototipe interaktif mandiri yang dikembangkan untuk menguji konsep visual *sliding authentication* (Spacer Auth) sebelum diintegrasikan secara penuh ke dalam antarmuka aplikasi Streamlit (`src/auth_ui.py` dan `src/styles.py`).

---

## 📂 Berkas Prototipe

| Nama Berkas | Format | Deskripsi |
| :--- | :--- | :--- |
| **`spacer_auth.html`** | HTML/CSS Standalone | Tampilan halaman autentikasi responsif dengan *Layered Vector Cloud Divider* dan transisi SPA login/register. |
| **`spacer_auth_slider.html`** | HTML/CSS Standalone | Varian prototipe dengan slider geser animasi visual interaktif. |
| **`SpacerAuth.jsx`** | React Component | Komponen React SPA yang mengimplementasikan *state management* formulir login/register dan validasi input. |
| **`SpacerAuthSlider.jsx`** | React Component | Komponen React lanjutan dengan animasi slider kontainer bergaya kartu ganda. |
